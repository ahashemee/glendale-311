Current challenge

The data can show a pattern exists, not why.

What the data can show
District X files fewer requests per 1,000 residents.

A measurable pattern.

What it doesn’t prove
District X has fewer problems.

That needs interpretation and more evidence.

Pattern ≠ Explanation
How we’ll handle it · Check each situation with the professor, keep findings separate from interpretation, and test statistically where it fits.
