1. On Tue 10-13, open every PNG in `outputs/iter2/*/` after the merge. For each chart, do the 5-second test: look for 5 seconds, then write what you think it says.

3. By Fri 10-16, write `run_sheet.md`: section order, speaker, target minutes, the transition line, and who scrolls the page. Add a 30-second buffer at the end.
4. At the Sunday 18:00 rehearsal, time each section and note any that run long.
